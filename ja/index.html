動画互換性

再生しやすい形式

拡張子だけでなく、ファイル内部の映像・音声コーデックによって実際の再生可否が決まります。

形式推奨コーデック目安
MP4 / M4VH.264 + AAC推奨
WebMVP8 / VP9 + Opus / Vorbis推奨
MOVH.264 + AAC一般的
OGVTheora + Vorbis環境依存
AVI / MKV内部コーデックによる保証なし

認識するコンテナ：MP4、MOV、M4V、WebM、OGV、AVI、MKV。WMVは非対応です。HEVC/H.265、特殊なプロファイル、破損ファイルは拡張子が対応していても再生できない場合があります。

初回起動

初回のみ、OSの警告解除が必要な場合があります。

macOS

この配布版はAppleの公証を受けていないため、「壊れているため開けません」と表示される場合があります。

  1. DMGを開き、アプリを「アプリケーション」フォルダへドラッグします。
  2. 「ターミナル」を開きます。
  3. 次のコマンドを貼り付けてReturnキーを押します。
  4. アプリケーションフォルダから起動します。
xattr -dr com.apple.quarantine "/Applications/Anyao Multi Video Player.app"

この公式ページから直接ダウンロードしたアプリに対してのみ実行してください。このコマンドは対象アプリの隔離属性だけを削除します。

Windows

インストーラーはコード署名されていないため、Microsoft Defender SmartScreenが警告を表示する場合があります。

  1. ダウンロードしたインストーラーを実行します。
  2. 「WindowsによってPCが保護されました」と表示されたら「詳細情報」を選びます。
  3. 発行元とファイル名を確認し、「実行」を選びます。

この公式ページのリンクから取得したファイルに対してのみ警告を解除してください。警告内容やファイル名が異なる場合は実行しないでください。

FAQ

よくある質問

Macはどちらを選べばよいですか？

M1以降はAppleシリコン版、Intelプロセッサ搭載MacはIntel版を選んでください。「Appleメニュー → このMacについて」で確認できます。

なぜOSから警告されるのですか？

現在の配布版はAppleの公証およびMicrosoftのコード署名を受けていないためです。必ずこの公式ページからダウンロードし、上記の初回起動手順に従ってください。

どの動画形式に対応していますか？

MP4/M4V（H.264/AAC）とWebM（VP8/VP9）を推奨します。対応拡張子でも内部コーデックによって再生できない場合があります。

Proの「上限なし」とは？

アプリが動画数・プレイリスト数を制限しないという意味です。実際に同時再生できる本数は、メモリ、GPU、解像度、ビットレート、コーデックに依存します。

ライセンスキーはどこで確認できますか？

購入時のPolarメールに記載されたリンク、またはPolar購入者ポータルで確認できます。

別の端末へ移行できますか？

古い端末のライセンス画面でDeactivate Licenseを実行してから、新しい端末で有効化してください。同時に最大5台まで利用できます。

アップデート方法は？

アプリを終了し、新しい版を上書きインストールしてください。アンインストールやライセンス解除は不要です。署名されていないため、更新後も初回起動警告が表示される場合があります。
