# GitHub Pages

This folder contains the product page for **Anyao Multi Video Player**.

The product links point to this public repository's Releases page. The application source code is maintained separately in a private repository and is not included here.

GitHub Pages publishes the site from the `main` branch and `/(root)`.

Downloads are served from GitHub Releases. Pro purchases are processed by Polar; the public checkout and all download links are configured in `site-config.js`.

## Search metadata

The canonical public URL is `https://anyao3.github.io/anyao-multi-video-player-site/`.

When the product version, download URLs, page paths, or public domain changes, update the matching values in:

- `index.html` metadata and `SoftwareApplication` structured data
- `legal.html` canonical and social metadata
- `sitemap.xml`
- `robots.txt`

Do not add fabricated ratings, reviews, download counts, or unsupported compatibility claims to structured data. After publishing, submit `sitemap.xml` in Google Search Console and request indexing for the canonical product URL.
